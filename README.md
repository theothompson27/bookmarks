# Theo Thompson's Bookmarks
A working list of design resources. Started from [Won J. You's bookmarks](https://github.com/wonjyou/bookmarks).

**Search:**
===
- [Google](https://www.google.com/)
- [Perplexity AI - AI-powered search for technical and design questions](https://www.perplexity.ai/)
- [vidIQ - YouTube keyword and channel research](https://vidiq.com/)
- [AnswerThePublic - search questions and keyword research](https://answerthepublic.com/)

_____________


**Community:**
===
- [ADPList](https://adplist.org/) - office hours with people doing the work
- [Design Slack Communities](https://www.designerslack.community/) - group chats for designers and producers
- [Pinterest](https://pinterest.com) - moodboards before anyone opens a deck
- [Dribbble](https://dribbble.com/) - single frames, mostly interface and web
- [Behance](https://www.behance.net/) - fuller projects, brand and campaign work
- [Figma Community](https://www.figma.com/community) - files and plugins other people published

**AI:**
===
- [Google Stitch](https://stitch.withgoogle.com/) - Google's prompt tool for interface
- [Google AI Studio](https://aistudio.google.com/) - a bench for trying Google's models
- [Figma Make](https://www.figma.com/ai/) - prompt a layout into the Figma file
- [v0 by Vercel](https://v0.dev/) - a prompt that comes back as React
- [Bolt.new](https://bolt.new/) - describe an app, then deploy it
- [Lovable](https://lovable.dev/) - a conversation that builds the app
- [Magic Patterns](https://www.magicpatterns.com/) - UI options generated for a system
- [Uizard](https://uizard.io/) - mockups from a sentence or a sketch
- [UXPilot](https://uxpilot.ai/) - wireframes and screens from a prompt
- [Galileo AI](https://www.usegalileo.ai/) - interface layouts from a text prompt
- [Grok Bots](https://docs.x.ai/grok-bot/overview) - AI teammates that take on work in your tools
- [Claude](https://claude.ai/) - Anthropic's conversational AI
- [ChatGPT](https://chatgpt.com/) - OpenAI's conversational AI
- [Gemini](https://gemini.google.com/) - Google's conversational AI
- [Midjourney](https://midjourney.com/) - AI image generation from text prompts
- [Higgsfield](https://higgsfield.ai/) - AI video and image generation
- [Adobe Firefly](https://www.adobe.com/products/firefly.html) - generative image and design tools from Adobe
- [Recraft](https://www.recraft.ai/) - image, vector, and style generation for design teams

**AI Skills & MCPs:**
===
- [21st.dev](https://21st.dev/) - AI-ready React and Tailwind component registry
- [21st MCP](https://21st.dev/mcp) - MCP for the 21st registry, formerly Magic MCP
- [Impeccable](https://impeccable.style/) - design skill for AI coding agents ([GitHub](https://github.com/pbakaus/impeccable))
- [comfyui-gen-mcp](https://github.com/lugia19/comfyui-gen-mcp) - MCP that runs ComfyUI image generation
- [frontend-design skill](https://github.com/anthropics/skills/tree/main/skills/frontend-design) - Anthropic's official skill for stronger UI from coding agents
- [Figma MCP server](https://help.figma.com/hc/en-us/articles/39216419318551-Get-started-with-the-Figma-MCP-server) - read and write Figma files from an AI agent
- [shadcn MCP](https://ui.shadcn.com/docs/mcp) - browse and install registry components from an assistant
- [Playwright MCP](https://github.com/microsoft/playwright-mcp) - browser automation for visual checks and QA

**Typography:**
